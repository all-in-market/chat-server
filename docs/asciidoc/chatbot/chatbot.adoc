== AI 챗봇

[[chat-stream]]
=== 챗봇 스트리밍 응답

`POST /chat/stream`

SSE(Server-Sent Events) 방식으로 AI 답변을 스트리밍합니다. +
`text/event-stream` 형식으로 응답이 청크 단위로 전달됩니다.
